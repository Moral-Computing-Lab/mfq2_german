# mfq2_german
A repository for analysis scripts related to the validation of the MFQ-2 in Germany.

The scripts will be uploaded to this repository upon completion of the study and acceptance of the final Stage 2 Registered Report.

This projekt is part of the following Registered Report:
Musa, N.S., Müller, S.M., & Hopp, F.R., (in prep). Validation of the Moral Foundations Questionnaire-2 (MFQ-2) in Germany: Psychometric properties and associations with political ideology, religiosity, and personality. http://dx.doi.org/10.23668/psycharchives.21651.
