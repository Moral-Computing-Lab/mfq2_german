# mfq2_german
A repository for code related to the validation of the MFQ2 in Germany.

The code will be accopmanying the following Stage 1 Registered Report: 

Musa, N.S., Müller, S.M., & Hopp, F.R., (in prep). Validation of the Moral Foundations Questionnaire-2 (MFQ-2) in Germany: Psychometric properties and associations with political ideology, religiosity, and personality
